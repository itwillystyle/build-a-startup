# HQ Lift 1b Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the tower's fade-and-teleport lift with a real cab that rides the shaft: a trophy panel that fills as you build, a sign that talks, the room label above the doors, a big phone floor list, riders carried smoothly by their own client.

**Architecture:** A pure `LiftPlan` module holds every rule (stops, ride time, ticks, the call queue, the trophy sockets, the room label, the rare-event roll) and is tested offline. Wafers builds the static parts (cab, landing doors, displays, the shaft cut). A new server module `LiftCab` owns each tower's cab state as attributes on the cab model and runs the queue; every client animates the cab from those attributes and carries its own character with it (the platform-delta method), so the ride is smooth for riders and watchers.

**Tech Stack:** Roblox Luau, Rojo 7.7 (files are the truth), Lune offline tests (`lune run tests/offline/run`), selene, the game doctor (`GameDoctor` + `DoctorProbes`) and `lune run tools/bas checkup pr`.

**Spec:** `silicon-startup/docs/superpowers/specs/2026-10-15-hq-lift-1b-design.md`

## Global Constraints
- Ride time: **1 s per floor, never over 4 s** (`LiftPlan.PER_STOP = 1.0`, `LiftPlan.CAP = 4.0`). Doors: **0.5 s** each way.
- A quiet tick per floor passed, a louder tick on the last, then the ding (`UIKit.sfx`: `tap` for ticks, `ding`).
- Calls queue; **riders already inside go first**; everyone inside rides together; doors closed everywhere while moving.
- **More than 6 riders**: "MAXIMUM CAPACITY. SOMEONE HAS TO GO." and the doors wait.
- Rare events: at most one per ride, odds 1 in 12, **never on the first 3 rides, never twice in a row**, never longer than the ride; lines: "PLEASE REMAIN CALM :)" (+ a ceiling panel flickers off 0.5 s), "THIS LIFT WAS BUILT BY " + the company name.
- Above the doors: one big number, an arrow, the room label (the department with the most built rooms on that floor, tie = the lowest seg's; "LOBBY", "ROOF GARDEN").
- Trophy panel: one socket per possible stop (LOBBY, every non-garden storey 1..13, ROOF GARDEN); built = lit with its number; a newly built one pops with a gold flash and "NEW!" once per session; desktop click on a lit button picks it.
- Phone: the floor list's rows are at least 44 px after scaling; nothing cut off.
- `LiftGo`'s checks carry over to calls: within 16 studs of one of THIS tower's stops, not Carrying, 1.2 s cooldown, `Movement.check`.
- No save change. No new top-level local in `SiliconCore.server.lua` (CONSTRAINTS rule 10). Neon only on lights and screens (rule 12). Studio tests as Wilz only; restore the save after every Play (wait ~4 s after Stop).
- Branch `hq-tower` (PR #56); 1b ships with 1a, 1c, 1d, never alone.

## Review Focus
1. **The roof stop:** the solid `Lantern` crown encloses the storey-14 shaft door (1a review Minor 4); a cab arriving at ROOF GARDEN must open onto open air, not a wall. -> Task 2 test "the roof stop opens onto the roof" + Task 2 makes the Lantern non-solid.
2. **A player standing in the doorway when the doors close** (half in the cab, half out): they must end up either inside and riding or outside on the landing, never in the shaft. -> Task 4: the server refuses to depart while a character overlaps the door line; live check in Task 6.
3. **The tower is rebuilt while the cab is mid-ride** (a BUILD tap, a spin-off, a respawn): no orphan cab, no rider left floating, no door left open on an empty shaft. -> Task 4: `LiftCab.sync` re-seats the cab at its current stop and finishes or cancels the ride; `LiftCab.reset` on clear; live check in Task 6.
4. **A stop that stops existing** (spin-off back to level 1, so only the lobby is left; a call queued for floor 7): the queue drops stops that no longer exist instead of riding to nowhere. -> Task 1 test "calls for stops that no longer exist are dropped".
5. **A rider who resets or leaves mid-ride:** the cab carries on; the next ride is not blocked. -> Task 4 counts riders by position at departure only; live check in Task 6.

```lua
--[[ LiftPlan (15 Oct 2026, HQ project #1 part 1b): the lift's rules. Pure.
	Spec: silicon-startup/docs/superpowers/specs/2026-10-15-hq-lift-1b-design.md. Wafers builds
	the parts, LiftCab (server) runs one cab per tower from these rules, LiftClient animates it. ]]
local T = require(script and script.Parent and script.Parent:FindFirstChild("TowerPlan") or "./TowerPlan")
local LP = {}

LP.PER_STOP, LP.CAP, LP.DOORS, LP.DWELL = 1.0, 4.0, 0.5, 3.0
LP.MAX_RIDERS, LP.EVENT_ODDS, LP.QUIET_RIDES = 6, 1 / 12, 3
LP.EVENT_TEXT = {
	calm = "PLEASE REMAIN CALM :)",
	pride = "THIS LIFT WAS BUILT BY %s",
	capacity = "MAXIMUM CAPACITY. SOMEONE HAS TO GO.",
}
LP.SHORT = { lobby = "LOBBY", eng = "ENG", studio = "STUDIO", cafe = "CAFE", servers = "SERVERS", labs = "AI LABS", board = "BOARD" }

function LP.stopId(s)
	if s == 0 then return "L" end
	if s >= 14 then return "R" end
	return "F" .. s
end

function LP.stops(pieces, level)
	local out = {}
	for s = 0, T.TOP do
		if T.landable(pieces, level, s) then table.insert(out, { storey = s, id = LP.stopId(s), label = T.label(s) }) end
	end
	return out
end

function LP.sockets(pieces, level)
	local out = {}
	for s = 0, 14 do
		if not T.DECKS[s] then
			table.insert(out, { storey = s, id = LP.stopId(s), num = (s == 0 and "L") or (s == 14 and "R") or tostring(s),
				built = T.landable(pieces, level, s) == true })
		end
	end
	return out
end

function LP.rideTime(n)
	n = math.abs(n or 0)
	if n == 0 then return 0 end
	return math.min(n * LP.PER_STOP, LP.CAP)
end

function LP.ticks(n)
	n = math.abs(n or 0)
	local out, dur = {}, LP.rideTime(n)
	for k = 1, n do table.insert(out, { t = dur * k / n, loud = (k == n) }) end
	return out
end

function LP.alpha(t, dur)
	if dur <= 0 then return 1 end
	local x = math.clamp(t / dur, 0, 1)
	return x * x * (3 - 2 * x)
end

-- the call queue: `at` is the stop index the cab is at; picks (from inside) before calls (from landings)
function LP.newCab(at) return { at = at or 1, calls = {}, picks = {}, rides = 0, lastEvent = false } end
local function add(list, idx) if not table.find(list, idx) then table.insert(list, idx) end end
function LP.call(cab, idx) add(cab.calls, idx) end
function LP.pick(cab, idx) add(cab.picks, idx) end
function LP.target(cab) return cab.picks[1] or cab.calls[1] end
function LP.arrive(cab, idx)
	cab.at = idx
	for _, list in ipairs({ cab.calls, cab.picks }) do
		local i = table.find(list, idx)
		if i then table.remove(list, i) end
	end
end
function LP.prune(cab, nStops)
	cab.at = math.clamp(cab.at, 1, math.max(nStops, 1))
	for _, list in ipairs({ cab.calls, cab.picks }) do
		for i = #list, 1, -1 do if list[i] > nStops then table.remove(list, i) end end
	end
end

function LP.rareEvent(ridesBefore, lastWasEvent, riders, roll)
	if riders > LP.MAX_RIDERS then return "capacity" end
	if ridesBefore < LP.QUIET_RIDES or lastWasEvent then return nil end
	if roll < LP.EVENT_ODDS / 2 then return "calm" end
	if roll < LP.EVENT_ODDS then return "pride" end
	return nil
end

function LP.roomLabel(pieces, depts, level, storey)
	if storey == 0 then return "LOBBY" end
	if storey >= 14 then return "ROOF GARDEN" end
	local count, firstSeg = {}, {}
	for L = 2, level do
		local pc = pieces[L]
		local d = depts[L]
		if pc and pc.kind == "segment" and pc.storey == storey and d then
			count[d] = (count[d] or 0) + 1
			firstSeg[d] = math.min(firstSeg[d] or 99, pc.seg)
		end
	end
	local best
	for d, n in pairs(count) do
		if not best or n > count[best] or (n == count[best] and firstSeg[d] < firstSeg[best]) then best = d end
	end
	return best and (LP.SHORT[best] or string.upper(best)) or ("FLOOR " .. storey)
end

return LP
```

```lua
--[[ LiftCab (15 Oct 2026, HQ project #1 part 1b): the server side of the tower's lift. One cab per
	tower. The rules are LiftPlan's (tested); this module keeps each cab's queue, opens and closes
	the landing doors, and publishes the ride as attributes on the cab model. It never moves the cab
	frame by frame: every client animates it from (FromY, ToY, Start, Dur) and carries its own
	character with it (LiftClient), then the server sets the cab's resting place on arrival. ]]
local RS = game:GetService("ReplicatedStorage")
local Players = game:GetService("Players")
local HttpService = game:GetService("HttpService")
local TweenService = game:GetService("TweenService")
local LP = require(RS:WaitForChild("LiftPlan"))
local T = require(RS:WaitForChild("TowerPlan"))
local Movement = require(game:GetService("ServerScriptService"):WaitForChild("Movement"))

local LiftCab = {}
local api = {}
local cabs = {}          -- plot.index -> { plot, model, plan, stops, busy }
local lastCall = {}      -- player -> os.clock()
local rng = Random.new()

local function stopIndex(c, id)
	for i, s in ipairs(c.stops) do if s.id == id then return i end end
	return nil
end

local function cabBox(c)
	local C = T.CAB
	return c.model.PrimaryPart.CFrame * CFrame.new(0, C.h / 2, 0), Vector3.new(C.w, C.h, C.d)
end
local function inside(c, pos, pad)
	local cf, size = cabBox(c)
	local l = cf:PointToObjectSpace(pos)
	pad = pad or 0
	return math.abs(l.X) <= size.X / 2 + pad and math.abs(l.Y) <= size.Y / 2 + pad and math.abs(l.Z) <= size.Z / 2 + pad
end
local function riders(c)
	local out = {}
	for _, p in ipairs(Players:GetPlayers()) do
		local root = p.Character and p.Character:FindFirstChild("HumanoidRootPart")
		if root and inside(c, root.Position, 0) then table.insert(out, p) end
	end
	return out
end
-- someone standing across the door line (half in, half out) keeps the doors open
local function inDoorway(c)
	local C = T.CAB
	local cf = c.model.PrimaryPart.CFrame
	for _, p in ipairs(Players:GetPlayers()) do
		local root = p.Character and p.Character:FindFirstChild("HumanoidRootPart")
		if root then
			local l = cf:PointToObjectSpace(root.Position)
			if math.abs(l.X) <= C.door / 2 + 0.5 and l.Y > -1 and l.Y < C.doorH and math.abs(l.Z - C.d / 2) < 1.6 then return true end
		end
	end
	return false
end

local function doorsAt(c, id, open)
	local folder = c.model.Parent
	if not folder then return end
	local C = T.CAB
	for _, side in ipairs({ "L", "R" }) do
		for _, leaf in ipairs(folder:GetChildren()) do
			if leaf.Name == "LiftDoor" .. side and leaf:GetAttribute("Stop") == id then
				local home = leaf:GetAttribute("Home") or leaf.CFrame
				leaf:SetAttribute("Home", home)
				local shift = (side == "L" and -1 or 1) * (C.door / 2 - 0.2) * (open and 1 or 0)
				leaf.CanCollide = not open
				TweenService:Create(leaf, TweenInfo.new(LP.DOORS, Enum.EasingStyle.Quad), { CFrame = home * CFrame.new(shift, 0, 0) }):Play()
			end
		end
	end
end

local function setDisplays(c, text, arrowUp)
	local arrow = arrowUp == nil and "" or (arrowUp and "^ " or "v ")
	local folder = c.model.Parent
	for _, d in ipairs(folder and folder:GetChildren() or {}) do
		if d.Name == "LiftDisplay" then
			local tl = d:FindFirstChildWhichIsA("SurfaceGui") and d:FindFirstChildWhichIsA("SurfaceGui"):FindFirstChild("Text")
			if tl then tl.Text = arrow .. text end
		end
	end
	local h = c.model:FindFirstChild("CabHeader")
	local tl = h and h:FindFirstChildWhichIsA("SurfaceGui") and h:FindFirstChildWhichIsA("SurfaceGui"):FindFirstChild("Text")

end

local function label(c, idx)

	if not st then return "" end

	local num = (st.id == "L" and "L") or (st.id == "R" and "R") or tostring(st.storey)

local function callLight(c, id, on)

	for _, p in ipairs(folder and folder:GetChildren() or {}) do
		if p.Name == "LiftCallLit" and p:GetAttribute("Stop") == id then
			p.Color = on and Color3.fromRGB(255, 160, 40) or Color3.fromRGB(255, 194, 61)

-- one ride or one door cycle, then loop while there is work
local function run(c)
	if c.busy then return end
	c.busy = true
	task.spawn(function()
		while c.model.Parent do
			local target = LP.target(c.plan)
			if not target then break end
			local here = c.stops[c.plan.at]
			if target == c.plan.at then
				LP.arrive(c.plan, target)
				callLight(c, here.id, false)
				if c.model:GetAttribute("State") ~= "open" then
					c.model:SetAttribute("State", "opening")
					doorsAt(c, here.id, true)
					task.wait(LP.DOORS)
					c.model:SetAttribute("State", "open")
				end
				task.wait(LP.DWELL)
				continue
			end
			-- leave: wait out the doorway and the capacity rule, then close
			local n = #riders(c)
			while c.model.Parent and (inDoorway(c) or n > LP.MAX_RIDERS) do
				if n > LP.MAX_RIDERS then
					c.model:SetAttribute("Event", "capacity")
					sign(c, LP.EVENT_TEXT.capacity)
				end
				task.wait(0.5)
				n = #riders(c)
			end
			c.model:SetAttribute("State", "closing")
			doorsAt(c, here.id, false)
			task.wait(LP.DOORS)
			local who = riders(c)
			local dest = c.stops[target]
			local floors = math.abs(target - c.plan.at)
			local dur = LP.rideTime(floors)
			local ev = LP.rareEvent(c.plan.rides, c.plan.lastEvent, #who, rng:NextNumber())
			c.plan.lastEvent = ev ~= nil
			local text = (target > c.plan.at) and "GOING UP!" or "GOING DOWN!"
			if ev == "calm" then text = LP.EVENT_TEXT.calm
			elseif ev == "pride" then
				local s = who[1] and api.session and api.session(who[1])
				text = LP.EVENT_TEXT.pride:format(string.upper((s and s.name ~= "" and s.name) or "YOU"))
			end
			sign(c, text)
			for _, p in ipairs(who) do p:SetAttribute("LiftCab", c.plot.index) end
			local fromY = c.model.PrimaryPart.Position.Y + 0.25
			local toCF = api.Wafers.cabAt(c.plot, dest.storey)
			c.model:SetAttribute("Event", ev or "")
			c.model:SetAttribute("FromY", fromY)
			c.model:SetAttribute("ToY", toCF.Position.Y)
			c.model:SetAttribute("Floors", floors)
			c.model:SetAttribute("Dur", dur)
			c.model:SetAttribute("Start", workspace:GetServerTimeNow())
			c.model:SetAttribute("To", dest.id)
			c.model:SetAttribute("State", "moving")
			setDisplays(c, label(c, target), target > c.plan.at)
			task.wait(dur)
			if not c.model.Parent then break end
			c.model:PivotTo(toCF * CFrame.new(0, -0.25, 0))
			c.plan.rides += 1
			LP.arrive(c.plan, target)
			c.model:SetAttribute("At", dest.id)
			for _, p in ipairs(who) do if p.Parent then p:SetAttribute("LiftCab", nil) end end
			callLight(c, dest.id, false)
			setDisplays(c, label(c, target), nil)
			sign(c, label(c, target))
			c.model:SetAttribute("State", "opening")
			doorsAt(c, dest.id, true)
			task.wait(LP.DOORS)
			c.model:SetAttribute("State", "open")
			c.model:SetAttribute("Event", "")
			task.wait(LP.DWELL)
		end
		c.busy = false
	end)
end

function LiftCab.sync(plot)
	local W = api.Wafers
	if not W then return end
	local st = W.stateOf(plot)
	local stops = LP.stops(W.Plan.PIECES, st.level)
	local c = cabs[plot.index]
	if #stops == 0 then LiftCab.reset(plot) return end
	if not c or not (c.model and c.model.Parent) then
		c = { plot = plot, model = W.cab(plot), plan = LP.newCab(1), stops = stops, busy = false }
		cabs[plot.index] = c
	end
	c.stops = stops
	LP.prune(c.plan, #stops)
	W.refreshPanel(plot, function(player, id) LiftCab.pick(player, plot.index, id) end)
	if c.model:GetAttribute("State") ~= "moving" then
		local here = stops[c.plan.at]
		c.model:PivotTo(W.cabAt(plot, here.storey) * CFrame.new(0, -0.25, 0))
		c.model:SetAttribute("At", here.id)
		doorsAt(c, here.id, true)
		c.model:SetAttribute("State", "open")
		setDisplays(c, label(c, c.plan.at), nil)
		sign(c, label(c, c.plan.at))
	end
	local list = {}
	for _, sk in ipairs(LP.sockets(W.Plan.PIECES, st.level)) do
		table.insert(list, { id = sk.id, num = sk.num, built = sk.built, label = sk.built and LP.roomLabel(W.Plan.PIECES, st.depts, st.level, sk.storey) or "",
			sub = T.DECKS[sk.storey - 1] and "TERRACE" or "" })
	end
	c.model:SetAttribute("Stops", HttpService:JSONEncode(list))
end

function LiftCab.reset(plot)
	cabs[plot.index] = nil
	for _, p in ipairs(Players:GetPlayers()) do
		if p:GetAttribute("LiftCab") == plot.index then p:SetAttribute("LiftCab", nil) end
	end
end

local function check(player, c)
	if player:GetAttribute("Carrying") then return false, "Drop off your recruit first" end
	if (lastCall[player] or 0) > os.clock() - 1.2 then return false, "busy" end
	if not Movement.check(player) then return false, "moving" end   -- standing at the lift, honestly
	return true

function LiftCab.call(player, plotIndex, stopId)
```

```lua
--[[ v9 (15 Oct, HQ part 1b): ride along. Samples the local character against the lift cab every
	frame for args.seconds: the biggest frame-to-frame change of its offset from the cab while the
	cab moves (a shake), whether it ever dropped below the cab floor (a fall), and the measured ride
	time (first to last frame the cab's State was "moving"). ]]
function Probes.liftride(args)
	local RS = game:GetService("RunService")
	local CS = game:GetService("CollectionService")
	local player = game:GetService("Players").LocalPlayer
	local cab
	for _, m in ipairs(CS:GetTagged("LiftCab")) do if m:GetAttribute("Plot") == args.plot then cab = m end end
	if not cab then return { error = "no cab" } end
	local t0, last, maxSlip, fell, movedFrom, movedTo = os.clock(), nil, 0, false, nil, nil
	while os.clock() - t0 < (args.seconds or 8) do
		RS.RenderStepped:Wait()
		local root = player.Character and player.Character:FindFirstChild("HumanoidRootPart")
		local base = cab.PrimaryPart
		if root and base then
			local off = base.CFrame:PointToObjectSpace(root.Position)
			local moving = cab:GetAttribute("State") == "moving"
			if moving then
				movedFrom = movedFrom or os.clock()
				movedTo = os.clock()
				if last then maxSlip = math.max(maxSlip, (off - last).Magnitude) end
				if off.Y < 0.5 then fell = true end
			end
			last = off
		end
	end
	return { maxSlip = math.floor(maxSlip * 100) / 100, fell = fell, rideSeconds = movedFrom and math.floor((movedTo - movedFrom) * 100) / 100 or -1 }
end
```
