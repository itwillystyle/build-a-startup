# HQ Part 1c: The Garage Becomes The Lobby. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the BUILD that turns a plot's garage into the lobby, the owner sees a ~4.4 s moment (scaffold, the garage folds flat, the lobby rises in steps with ticks and a sting, a look-up, the camera back), skippable; plus the garage chair moved clear of the lift shaft, and the garage TV and a "WHERE IT STARTED" photo on the lobby wall.

**Architecture:** A pure `LobbyMoment` module owns the timeline (groups, easing, sounds, camera shots) and is tested offline. The server builds the real lobby at once as today (no `Rise` on this build) and fires one remote, `SVRemotes.LobbyMoment`, to the owner with the new pieces. A client script plays the moment locally on those parts and on a client-only copy of the garage (kept while the plot is at level 1), using `Cine` for the camera, then snaps every part to where the server has it.

**Tech Stack:** Roblox Luau, Rojo (files are the truth), Lune offline tests (`lune run tests/offline/run`), selene, Studio MCP for live checks (Wilz only).

**Spec:** `silicon-startup/docs/superpowers/specs/2026-10-15-hq-garage-1c-design.md`

## Global Constraints
- The moment is at most 4.5 s (`LobbyMoment.TOTAL` = 4.4). Skip at any time gives the end state.
- It plays only on the BUILD that takes the plot from level 1 to 2 or more (the first company and after each spin-off); never on a save load, a rejoin, `releasePlot`, or a dev `hq:<n>`.
- Only the owner's client plays it. The server's final state never depends on it.
- The floor, the desk, the laptop and the hire pad never move. The player is never moved by the moment.
- The camera is handed back as Custom with the player's Humanoid as subject (`Cine.handBack`).
- No popup after it: one toast line, "Your HQ is open! Next: floor 1."
- CONSTRAINTS rule 10: no new top-level local in `SiliconCore.server.lua`. Rule 12: Neon only on lights and screens. Rule 4: judge/test-rule changes in their own commits (none planned).
- Pure `ReplicatedStorage` modules require no sibling; offline tests load pure modules only.
- Code is delivered as files in the repo (Luke's rule); no saved-data change.

## Review Focus
1. **The finish picker before it** (a company's very first build): the picker closes, then the moment starts; nothing stays hidden or open afterwards, the camera is Custom.
2. **A reload, a rejoin or a dev `hq:<n>` at level 2+:** no moment; **after a spin-off,** the next BUILD from the garage plays it again.
3. **Skip at the very start or the very end:** every lobby part visible and in place, the garage copy and the scaffold gone, the toast once.
4. **No garage copy on the client** (it joined while the plot was above level 1, or the garage never streamed in): the moment starts at the scaffold, no error.
5. **The player is moved during the moment** (the server's "new walls closed round you" rule pivots them to spawn 0.3 s after the build): the camera still ends on the player (Custom, subject = their Humanoid).

local LM = require("../../src/ReplicatedStorage/LobbyMoment")
local TT = {}
local function test(name, fn) table.insert(TT, { name = name, fn = fn }) end

	for _, s in ipairs(LM.STEPS) do

	end

	local order = {}
	for _, s in ipairs(LM.STEPS) do order[s.group] = s.from end
	assert(order.scaffold < order.garage and order.garage < order.columns and order.columns < order.glass, "first half")

	local sum = 0

	assert(near(sum, LM.TOTAL), "shots sum to TOTAL")
	assert(LM.SHOTS[1].at == "start" and LM.SHOTS[#LM.SHOTS].at == "player", "from the player and back")

```lua
--[[ LobbyMoment (15 Oct 2026, HQ project #1 part 1c): the garage-to-lobby moment's timeline. Pure.
	Spec: silicon-startup/docs/superpowers/specs/2026-10-15-hq-garage-1c-design.md. The server builds
	the real lobby at once; LobbyMomentClient plays this on the owner's screen and snaps every part
	back to where the server has it. Positions are plot space: x across, y up, z toward the street. ]]
local LobbyMoment = {}

LobbyMoment.TOTAL = 4.4
LobbyMoment.SKIP_FADE = 0.3
LobbyMoment.RISE = 8     -- studs a lobby group rises from
LobbyMoment.LIFT = 6     -- studs the garage's roof and props lift as they fade

-- each group moves from `from` to `to`; the scaffold also leaves (outFrom to outTo)
LobbyMoment.STEPS = {
	{ group = "scaffold", from = 0.0, to = 0.6, outFrom = 2.6, outTo = 3.1 },
	{ group = "garage", from = 0.6, to = 1.2 },
	{ group = "columns", from = 1.2, to = 1.8 },
	{ group = "glass", from = 1.8, to = 2.4 },
	{ group = "roof", from = 2.2, to = 2.5 },
	{ group = "canopy", from = 2.6, to = 3.0 },
}

-- existing UIKit.SOUNDS keys: a thunk as it starts and as the garage lands, a tick per step, the sting
LobbyMoment.SOUNDS = {
	{ t = 0.0, key = "thunk", pitch = 0.7, volume = 0.35 },
	{ t = 1.2, key = "thunk", pitch = 0.9, volume = 0.55 },
	{ t = 1.8, key = "tap", pitch = 1.2, volume = 0.5 },
	{ t = 2.4, key = "tap", pitch = 1.5, volume = 0.55 },
	{ t = 2.5, key = "levelup", pitch = 1.0, volume = 0.8 },
}

-- the camera (Cine shots): from where it is, a wide shot that drifts (and holds as the roof lands),
-- a low look-up at the glass, then back to the player. t = seconds to reach that shot.
LobbyMoment.SHOTS = {
	{ at = "start", t = 0 },
	{ pos = { -40, 38, 100 }, look = { 0, 9, 10 }, t = 0.6 },
	{ pos = { -34, 34, 92 }, look = { 0, 10, 10 }, t = 2.05 },
	{ pos = { 22, 2, 88 }, look = { -4, 18, 30 }, t = 0.6 },
	{ pos = { 18, 2.5, 82 }, look = { -4, 19, 30 }, t = 0.35 },
	{ at = "player", t = 0.8 },
}

-- back-out easing: 0 at 0, 1 at 1, about 5% past 1 on the way (each step "lands")
function LobbyMoment.ease(u)
	u = math.clamp(u, 0, 1)
	local c1 = 1.2
	local c3 = c1 + 1
	local v = u - 1
	return 1 + c3 * v * v * v + c1 * v * v
end

local function step(group)
	for _, s in ipairs(LobbyMoment.STEPS) do if s.group == group then return s end end
	return nil
end

-- how far a group is at time t: 0 = not there yet (the garage: still standing), 1 = in place (the
-- garage: gone). The scaffold goes up and comes down again, so it ends at 0.
function LobbyMoment.at(group, t)
	local s = step(group)
	if not s then return 1 end
	local p
	if t <= s.from then p = 0
	elseif t >= s.to then p = 1
	else p = LobbyMoment.ease((t - s.from) / (s.to - s.from)) end
	if s.outFrom and t > s.outFrom then
		p = 1 - math.clamp((t - s.outFrom) / (s.outTo - s.outFrom), 0, 1)
	end
	return p
end

local GROUP = { Column = "columns", RoofBand = "roof", Ceiling = "roof", LobbyCanopy = "canopy", Floor = "floor", Deck = "floor" }
function LobbyMoment.groupOf(name)
	return GROUP[name] or (string.sub(name, 1, 4) == "Sign" and "canopy") or "glass"
end

-- which way a garage part folds: a wall on a side folds out on that side; the roof, anything that
-- spans the whole garage (the shell mesh) and anything low (boxes, props) lifts away and fades.
-- x, z: the part's centre from the garage's centre; sx, sy, sz: its size; hw, hd: the garage's half size
function LobbyMoment.foldSide(x, z, sx, sy, sz, hw, hd)
	if sy < 3 or (sx >= hw * 1.2 and sz >= hd * 1.2) then return "lift" end
	if math.abs(x) >= hw - 1.5 and sz > sx then return x > 0 and "px" or "nx" end
	if math.abs(z) >= hd - 1.5 and sx >= sz then return z > 0 and "pz" or "nz" end
	return "lift"
end

return LobbyMoment
```

**Files:**

**Interfaces:**

- [ ] **Step 1: Write the client**

```lua
--[[ LobbyMomentClient (v9, 15 Oct 2026, HQ part 1c): the garage becomes the lobby.
	The server has already built the lobby (and stashed the garage) when LobbyMoment arrives. This
	plays the ~4.4 s moment on this screen only: scaffold up, the garage (a copy kept while we were at
	level 1) folds flat, the lobby's columns, glass and roof rise in steps with a tick each and a sting,
	the scaffold drops, a look-up, the camera back to you. Skip at any time. Every lobby part ends
	exactly where the server has it, whatever happens. Spec: docs/superpowers/specs/2026-10-15-hq-garage-1c-design.md ]]
local Players = game:GetService("Players")
local RS = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")

local player = Players.LocalPlayer
local T = require(RS:WaitForChild("TowerPlan"))
local LM = require(RS:WaitForChild("LobbyMoment"))
local Cine = require(RS:WaitForChild("Cine"))
local UIKit = require(RS:WaitForChild("UIKit"))
local Notify = require(RS:WaitForChild("Notify"))
local remote = RS:WaitForChild("SVRemotes"):WaitForChild("LobbyMoment")

-- ---------------------------------------------------------------- the garage, kept while we are in one
local copy           -- a Model: everything Wafers.garage will stash, never parented until the moment
local STRIP = { ProximityPrompt = true, ClickDetector = true, Script = true, LocalScript = true,
	ModuleScript = true, Sound = true, ParticleEmitter = true }
local function garageFolder()
	local sv = workspace:FindFirstChild("SiliconValley")
	local plots = sv and sv:FindFirstChild("Plots")
	local p = plots and plots:FindFirstChild("Plot" .. tostring(player:GetAttribute("Plot")))
	return p and p:FindFirstChild("Garage")
end
local function snapshot()
	if (player:GetAttribute("WaferLevel") or 1) > 1 then return end
	local g = garageFolder()
	if not g then return end
	local m = Instance.new("Model")
	m.Name = "GarageCopy"
	for _, c in ipairs(g:GetChildren()) do
		if not T.GARAGE_KEEP[c.Name] and not STRIP[c.ClassName] then
			local ok, k = pcall(function() return c:Clone() end)
			if ok and k then
				for _, d in ipairs(k:GetDescendants()) do if STRIP[d.ClassName] then d:Destroy() end end
				k.Parent = m
			end
		end
	end
	if #m:GetChildren() == 0 then m:Destroy() return end
	if copy then copy:Destroy() end
	copy = m
end
player:GetAttributeChangedSignal("WaferLevel"):Connect(function()
	if (player:GetAttribute("WaferLevel") or 1) <= 1 then task.delay(2, snapshot) end   -- a spin-off: a garage again
end)
task.delay(5, snapshot)

-- ---------------------------------------------------------------- the moment
local function vec(pivot, v) return (pivot * CFrame.new(v[1], v[2], v[3])).Position end

local function scaffoldAround(pivot, x0, x1, z0, z1, y0, h)
	local m = Instance.new("Model")
	m.Name = "MomentScaffold"
	local function bar(cf, size, color, transparency)
		local p = Instance.new("Part")
		p.Anchored, p.CanCollide, p.CanQuery, p.CanTouch, p.CastShadow = true, false, false, false, false
		p.Size, p.CFrame, p.Color, p.Material = size, cf, color, Enum.Material.SmoothPlastic
		p.Transparency = transparency or 0
		p.Parent = m
	end
	local steel, band = Color3.fromRGB(150, 156, 166), Color3.fromRGB(40, 110, 230)   -- world colours
	x0, x1, z0, z1 = x0 - 2, x1 + 2, z0 - 2, z1 + 2
	for x = x0, x1, 6 do for _, z in ipairs({ z0, z1 }) do bar(pivot * CFrame.new(x, y0 + h / 2, z), Vector3.new(0.3, h, 0.3), steel) end end
	for z = z0, z1, 6 do for _, x in ipairs({ x0, x1 }) do bar(pivot * CFrame.new(x, y0 + h / 2, z), Vector3.new(0.3, h, 0.3), steel) end end
	for y = y0 + 4, y0 + h - 1, 6 do
		for _, z in ipairs({ z0, z1 }) do bar(pivot * CFrame.new((x0 + x1) / 2, y, z), Vector3.new(x1 - x0, 0.25, 0.25), steel) end
		for _, x in ipairs({ x0, x1 }) do bar(pivot * CFrame.new(x, y, (z0 + z1) / 2), Vector3.new(0.25, 0.25, z1 - z0), steel) end
	end
	-- the blue "still building" band round the top
	for _, z in ipairs({ z0 - 0.3, z1 + 0.3 }) do bar(pivot * CFrame.new((x0 + x1) / 2, y0 + h - 2, z), Vector3.new(x1 - x0, 4, 0.15), band, 0.25) end
	for _, x in ipairs({ x0 - 0.3, x1 + 0.3 }) do bar(pivot * CFrame.new(x, y0 + h - 2, (z0 + z1) / 2), Vector3.new(0.15, 4, z1 - z0), band, 0.25) end
	m.Parent = workspace
	return m
end

local playing = false
local function play(e)
	if playing or typeof(e) ~= "table" or typeof(e.pivot) ~= "CFrame" then return end
	playing = true
	local pivot = e.pivot
	local up = pivot.UpVector

	-- the lobby's parts by group, with where the server has them
	local groups = { columns = {}, glass = {}, roof = {}, canopy = {} }
	local lo, hi = Vector3.new(math.huge, math.huge, math.huge), Vector3.new(-math.huge, -math.huge, -math.huge)
	local function add(p)
		if not p:IsA("BasePart") or p.Transparency >= 1 then return end
		local list = groups[LM.groupOf(p.Name)]
		if not list then return end   -- the floor stays put
		table.insert(list, { part = p, cf = p.CFrame })
		local l = pivot:PointToObjectSpace(p.Position)
		lo, hi = lo:Min(l), hi:Max(l)
	end
	for _, m in ipairs(e.models or {}) do
		if typeof(m) == "Instance" then for _, d in ipairs(m:GetDescendants()) do add(d) end end
	end
	for _, p in ipairs(e.core or {}) do if typeof(p) == "Instance" then add(p) end end
	if typeof(e.cab) == "Instance" then for _, d in ipairs(e.cab:GetDescendants()) do add(d) end end

	-- the garage copy: each part folds out on its side, or lifts away
	local garage = copy
	copy = nil
	local folds = {}
	if garage then
		garage.Parent = workspace
		local glo, ghi = Vector3.new(math.huge, math.huge, math.huge), Vector3.new(-math.huge, -math.huge, -math.huge)
		local parts = {}
		for _, d in ipairs(garage:GetDescendants()) do
			if d:IsA("BasePart") then
				d.Anchored, d.CanCollide, d.CanQuery, d.CanTouch = true, false, false, false
				local l = pivot:PointToObjectSpace(d.Position)
				glo, ghi = glo:Min(l), ghi:Max(l)
				table.insert(parts, d)
			end
		end
		local c = (glo + ghi) / 2
		local hw, hd = (ghi.X - glo.X) / 2, (ghi.Z - glo.Z) / 2
		for _, d in ipairs(parts) do
			local l = pivot:PointToObjectSpace(d.Position)
			local side = LM.foldSide(l.X - c.X, l.Z - c.Z, d.Size.X, d.Size.Y, d.Size.Z, hw, hd)
			local hinge
			if side == "px" then hinge = Vector3.new(c.X + hw, glo.Y, l.Z)
			elseif side == "nx" then hinge = Vector3.new(c.X - hw, glo.Y, l.Z)
			elseif side == "pz" then hinge = Vector3.new(l.X, glo.Y, c.Z + hd)
			elseif side == "nz" then hinge = Vector3.new(l.X, glo.Y, c.Z - hd) end
			table.insert(folds, { part = d, cf = d.CFrame, side = side, hinge = hinge })
		end
	end

	-- the scaffold round the new build
	local scaffold
	if lo.X < math.huge then
		scaffold = scaffoldAround(pivot, lo.X, hi.X, lo.Z, hi.Z, lo.Y, (hi.Y - lo.Y) + 2)
	end
	local scaffoldCF = scaffold and scaffold:GetPivot()
	local scaffoldH = (hi.Y - lo.Y) + 2

	local function apply(t)
		for name, list in pairs(groups) do
			local p = LM.at(name, t)
			local off = up * (-LM.RISE * (1 - p))
			local hide = 1 - math.clamp(p, 0, 1)
			for _, it in ipairs(list) do
				it.part.CFrame = it.cf + off
				it.part.LocalTransparencyModifier = hide
			end
		end
		if scaffold then scaffold:PivotTo(scaffoldCF + up * (-scaffoldH * (1 - LM.at("scaffold", t)))) end
		local g = LM.at("garage", t)
		for _, f in ipairs(folds) do
			if f.side == "lift" then
				f.part.CFrame = f.cf + up * (LM.LIFT * g)
				f.part.LocalTransparencyModifier = math.clamp(g, 0, 1)
			else
				local a = math.rad(90) * math.clamp(g, 0, 1)
				local rot = (f.side == "px" and CFrame.Angles(0, 0, -a)) or (f.side == "nx" and CFrame.Angles(0, 0, a))
					or (f.side == "pz" and CFrame.Angles(a, 0, 0)) or CFrame.Angles(-a, 0, 0)
				local h = pivot * CFrame.new(f.hinge)
				f.part.CFrame = h * rot * h:Inverse() * f.cf
			end
		end
	end

	local done = false
	local function finish()
		if done then return end
		done = true
		for _, list in pairs(groups) do
			for _, it in ipairs(list) do
				if it.part.Parent then it.part.CFrame = it.cf; it.part.LocalTransparencyModifier = 0 end
			end
		end
		if scaffold then scaffold:Destroy() end
		if garage then garage:Destroy() end
	end

	-- hide the new lobby before the first frame, then run the clock beside Cine's camera
	apply(0)
	local t0 = os.clock()
	local soundIdx = 1
	local conn
	conn = RunService.RenderStepped:Connect(function()
		local t = os.clock() - t0
		while LM.SOUNDS[soundIdx] and LM.SOUNDS[soundIdx].t <= t do
			local s = LM.SOUNDS[soundIdx]
			UIKit.sfx(s.key, s.pitch, s.volume)
			soundIdx += 1
		end
		if t >= LM.TOTAL or (t > 0.2 and not Cine.busy()) then
			conn:Disconnect()
			finish()
			return
		end
		apply(t)
	end)

	-- the camera
	local cam = workspace.CurrentCamera
	local shots = {}
	for _, s in ipairs(LM.SHOTS) do
		if s.at == "start" then
			table.insert(shots, { pos = cam.CFrame.Position, look = cam.CFrame.Position + cam.CFrame.LookVector * 20, t = 0 })
		elseif s.at == "player" then
			local head = player.Character and player.Character:FindFirstChild("Head")
			local look = head and head.Position or cam.Focus.Position
			table.insert(shots, { pos = cam.CFrame.Position, look = look, t = s.t })
		else
			table.insert(shots, { pos = vec(pivot, s.pos), look = vec(pivot, s.look), t = s.t })
		end
	end
	local ok, finished = pcall(Cine.play, shots, { letterbox = true, skippable = true, fov = 60 })
	if not (ok and finished) then
		-- skipped (or Cine refused): a short fade over the jump to the end state
		Cine.fade(true, LM.SKIP_FADE / 2)
		task.wait(LM.SKIP_FADE / 2)
		if conn.Connected then conn:Disconnect() end
		finish()
		Cine.handBack()
		Cine.fade(false, LM.SKIP_FADE / 2)
	else
		if conn.Connected then conn:Disconnect() end
		finish()
	end
	pcall(Notify.toast, "Your HQ is open! Next: floor 1.", { priority = 2, icon = "info" })
	playing = false
end

remote.OnClientEvent:Connect(function(e)
	local ok, err = pcall(play, e)
	if not ok then
		warn("[SV] lobby moment: " .. tostring(err))
		playing = false
	end
end)
```
