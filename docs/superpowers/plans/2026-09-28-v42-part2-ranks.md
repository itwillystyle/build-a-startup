# v4.2 Part 2: Ranks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A RANKS button on the HUD opens a global leaderboard (THIS WEEK / ALL TIME) of every company from $1,000 of value, with your own row pinned and the gap to the next company.

**Architecture:**
- **Server:** `ServerScriptService.Ranks` (ModuleScript).
  - Pure rules: `weekId`, `rollWeek`, `merge`, `mine`.
  - A board object that takes its stores as arguments (testable with fakes).
  - `Ranks.init(api)` runs the live loop: push each player once a minute, read both boards once a minute, cache them, and answer a `GetRanks` RemoteFunction.
- **SiliconCore:** gains hooks only, no new top-level locals (it is at Luau's 200-local limit).
- **Client:** `RanksClient` draws the panel.

**Tech Stack:** Roblox Luau, OrderedDataStore, Studio MCP, the localhost install pipe (`tools/install.luau`).

## Global Constraints
- Spec Part 2: the number is lifetime `valuation`. Boards: `SVTicker_v1` (all time) and `SVWeek_<weekId>` (weekly, Monday 00:00 UTC). A company joins from $1,000. Top 25. AI rivals tagged AI.
- Writes: at most one per board per player per minute, only on change. Reads: once a minute per server. `GetRanks` never touches a DataStore.
- No new top-level locals in SiliconCore. Leave Studio in Edit. Snapshot/restore his record around live tests. Disk == Studio.
