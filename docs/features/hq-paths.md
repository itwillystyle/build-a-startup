# HQ paths (Wafers, Terrafab, Dome)
**What:** The HQ is one tower of up to 100 pieces ("levels"). Each BUILD tap adds the next piece. The first tap above the garage asks the player to pick a style: Wafers (`W_`), Terrafab (`T_`) or Dome (`D_`). All three styles use one placer and one plan, only the mesh prefix changes (`src/ServerScriptService/Wafers.lua:108-125`). The old "HQ 1-5" is now a stage worked out from the level (`Wafers.lua:166-171`: 5, 9, 13, 18).
**How a player reaches it:**
1. Ship a product and hire one person (`src/ServerScriptService/SiliconCore.server.lua:2060-2061`).
2. Tap BUILD (rail tile, HQ pad prompt "UPGRADE" at `SiliconCore.server.lua:2858`). The card fires `WaferBuild` (`:2801`) into `tryUpgrade` (`:2161`) then `wafersBuild` (`:2052`).
3. First build only: no `s.hqPath` and level 1 or less. The server fires `AskPath` and builds nothing (`:2074-2079`). The picker fires `WaferPath` (`WaferClient.client.lua:352`). The server saves the path and calls `tryUpgrade` again (`:2814-2833`).
4. Stage 2 (level 5) gives the company car (`:2139-2140`). A new stage, or level 43, 68, 93 or 100, plays the level-up banner (`:2051`, `:2137-2155`).
5. Lifts: the glass core in the courtyard. Prompt "Take the lift" (`Wafers.lua:1400-1408`) opens `LiftMenu`. Tapping a stop fires `LiftGo` (`src/ServerScriptService/HQFloors.lua:81-135`).
6. At the company's level cap the pad becomes GO PUBLIC, then spin-off (`SiliconCore.server.lua:2054-2058`).

**Drive it:**
- `dev:Invoke("scenario", p, "hq:<n>")` runs raw `wlevel n` (`DevScenarios.lua:193`, `DevHook.lua:65-81`). It builds free up to n, capped by the company's blueprint (18 for company one).
- Raw `upgrade` calls `tryUpgrade` (`DevHook.lua:62`). `tp:hq` teleports to the HQ pad (`DevScenarios.lua:215`).
- Choosing a path: none yet. `wlevel` skips the picker, and `WaferPath` is refused above level 1 (`SiliconCore.server.lua:2820-2823`). Untested idea: fire `WaferPath` from the client at level 1.
**Prove it:**
- `tests/offline/wafer.spec.luau` with `tests/offline/wafer_golden.json`: WaferPlan matches the sim (100 pieces, prices, caps, departments, effects, rebuild share, blueprint).
- `tests/offline/hqmeta.spec.luau`: every `W_` name the placer asks for has a META entry in all three kits, the kits list the same pieces (Terrafab has no PodiumGlass on purpose), sizes are real, Podium and Crown exist. It does not check V1 or V2.
- `SVCheck` (Studio, client, `src/ReplicatedStorage/SVCheck.lua:700-750`): furniture inside the glass line, using `WaferPlan.INSET`. See the Gotchas: it may silently skip on the client.
- `tests/smoke_core.luau`: Studio before/after diff of `upgrade`. It changes the save.
- No automated check yet for the path picker, the lift, the car grant or the rocket.
**Gotchas:**
- A missing META entry is silent. The placer builds primitives instead (`Wafers.lua:306-313`, `HQMeta/init.lua:14-16`).
- `CUR` is one module variable. `Wafers.anchor` resets it at the start of every build function (`Wafers.lua:109, 179-181`). An unknown path falls back to `W_` (:111-114).
- On load, `plot.hqPath` must be set before the rebuild. Otherwise a Dome player gets Wafers meshes with Dome collision, an invisible wall in the doorway (`SaveLoad.lua:219-235`).
- The picker says "You can change it when you spin off" (`WaferClient.client.lua:210`). I found no code that clears `hqPath` on spin-off (`releasePlot` :2864 does not). Looks unfinished. Unverified in Studio.
- `WaferPlan.lua:20-21` (`CAR_AT`, `APT_FROM` and kin) are read by nothing in src. The header at :15 ("Not wired into the game yet") is stale. Real gates use `Wafers.stage`.
- The SVCheck glass pass requires `WaferPlan` from ReplicatedStorage or ServerScriptService (`SVCheck.lua:716-717`). `default.project.json:13-16` maps it only to ServerScriptService, which clients cannot see. The pcall probably fails and the pass reads "0 out, 0 in". Unclear. Not run.
- The style gate is inside `wafersBuild`, because the card, pad prompt and click are three ways in (`SiliconCore.server.lua:2063-2073`).
- Lift buttons must be tracked in `st.core`, or each rebuild leaves duplicate prompts (`Wafers.lua:1381-1393`).
- `LiftGo` needs you within 16 studs of a stop, blocks while Carrying, has a 1.2 s cooldown and stands you up from a car first (`HQFloors.lua:95-126`).
- In Wafers mode `buildShell` runs only for the level 1 garage (`SiliconCore.server.lua:1053`). By the code, `skinHQ` only skins the level 1 garage and the V2 meshes are never used while Wafers is on (`SaveLoad.lua:258-260`, `SiliconCore.server.lua:2165`).
- Rocket position uses `CFG.HQ_LEVELS[stage].h`, not the tower (`SiliconCore.server.lua:3229-3232`). Unclear if it matches a tall tower's roof.
